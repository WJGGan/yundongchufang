# 个人健康档案（体质画像）微调模型测评报告

> **适用范围**：基于 `finetune/profile_sft_sample.json` 格式数据（输入 = 学生健康档案 + 检索知识卡片，输出 = 严格 Schema 的体质画像 JSON）微调的体质画像生成模型。
>
> **指标依据**：
> - 《运动健康大模型需求文档 20260715》第七章技术指标（指标 1 体质画像 F1 ≥ 85%、指标 2 损伤风险预警准确率 ≥ 90%）、第六章安全需求；
> - 《运动健康模型开发方案_第一版》第六节交付成果与验收建议（评测案例 ≥ 200 例且与训练集隔离；硬规则拦截率 100%、关键计算正确率 100%、结构化输出有效率 ≥ 99%、专家综合合格率 ≥ 90%；按安全、科学性、个体化、可执行性、来源一致性综合评分）。
>
> 填写约定：`实测值` 留空处填数值；`达标` 列填 ✅ / ❌；不适用填 N/A。
